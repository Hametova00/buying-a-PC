# Покупка в DNS — визуальная новелла на Twine

Интерактивная новелла, сделанная в **Twine 2** (формат историй **SugarCube 2.37.3**).
Робот-консультант Ника помогает игроку собрать игровой компьютер или выбрать ноутбук для учёбы.

## Как играть
- Онлайн: открыть ссылку GitHub Pages этого репозитория.
- На компьютере: скачать `index.html` и открыть в браузере.

## Структура
| Файл | Что это |
|---|---|
| `index.html` | Опубликованная игра Twine (играется в браузере, нужна для GitHub Pages) |
| `twine-source/pokupka_dns_twine.html` | Тот же файл Twine для импорта в программу Twine |
| `twine-source/pokupka_dns.twee` | Исходный текст истории в формате Twee 3 |
| `sprites/` | Спрайты героини Ники (PNG с прозрачным фоном) |

## Как открыть в Twine
1. Открыть Twine 2 (приложение или https://twinery.org).
2. Библиотека → **Импорт** → выбрать `twine-source/pokupka_dns_twine.html`.
3. История откроется со всеми сценами; формат — SugarCube 2.

Цены в игре — ориентировочные (DNS, ноябрь 2026).
